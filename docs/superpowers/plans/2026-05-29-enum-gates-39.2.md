## Step 2 — `gates/draft-read.ts` (verbatim extraction; AC-1, AC-7)

**Test first:** `tests/gates/draft-read.test.ts` — ctx-builder like
`coverage.test.ts`, stubbing `draftMtimeMs` + `state.draftReadAt`:
- mtime > baseline, no bypass → `refuse`, exact stderr message.
- mtime > baseline, `allowStaleDraft` → `pass`, exact "--allow-stale-draft" note.
- mtime ≤ baseline → `pass`, no stderr.
- `draftReadAt === null` → `pass` (guard preserved).
- `draftMtimeMs()` returns `null` → `pass` (no DRAFT / stat fail).

**Impl:** `runDraftReadGate: GateImpl`. Reads `ctx.state.draftReadAt`,
`await ctx.draftMtimeMs()`; reproduce `settle.ts:175-186` messages verbatim via
`ctx.io.err`. Returns pure pass/refuse (no `summaryPatch`/`flags`).

## Step 3 — `gates/structural-verifier.ts` (new; AC-2)

**Test first:** `tests/gates/structural-verifier.test.ts`:
- task `IN_PROGRESS` → refuse, per-task line + summary line (exact).
- task `PENDING` → refuse.
- all of {DONE, DONE_WITH_CONCERNS, NEEDS_CONTEXT, BLOCKED} → pass.
- open task + `allowOpenTasks` → pass, no stderr.
- open task + `force` → pass, no stderr.
- empty `tasks` → pass.

**Impl:** `TERMINAL = new Set(['DONE','DONE_WITH_CONCERNS','NEEDS_CONTEXT','BLOCKED'])`;
iterate `ctx.progress.tasks`; refuse on any non-terminal unless
`allowOpenTasks`/`force`. Messages per design §Implementation Pattern.

## Step 4 — `gates/build-test-must-pass.ts` (new; AC-3)

**Test first:** `tests/gates/build-test-must-pass.test.ts` — stub `ctx.runner`:
- `{ran:false}` → pass + "no verification.testCommand configured" note.
- `{ran:true, ok:true}` → pass, no stderr.
- `{ran:true, ok:false, exitCode:1, command:'pnpm test'}` → refuse, 2 stderr lines.
- `ok:false` + `allowFailingBuild` → pass.
- `ok:false` + `force` → pass.

**Impl:** `runBuildTestGate: GateImpl` per design. Reaches the subprocess only
through `ctx.runner` — no `child_process` import in the gate.

## Step 5 — Settle wiring + CLI flags (AC-9)

1. `settle.ts`:
   - Add CLI options `--allow-open-tasks`, `--allow-failing-build`; extend the

## Risk notes

- **draft-read reorder.** It moves below the ctx build; verify softCap still
  fires first and draft-read still precedes coverage (transcript test).
- **runner subprocess.** Only the settle-side adapter touches `child_process`;
  gate + gate-tests stay spawn-free. `execSync` throwing on non-zero is the
  documented exit-code source.
- **No `summaryPatch` from the new gates.** `SettleAccumulator` unchanged;
  finalizers untouched — lowest blast radius.
