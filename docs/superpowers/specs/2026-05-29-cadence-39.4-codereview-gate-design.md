# CADENCE Phase 39.4 — Lift the code-review gate (+ convergence sidecar) into `gates/code-review.ts` — Design + Plan

> Fourth v1.3.0 phase, and the heaviest. Extracts the Phase 24.3 code-review
> gate **and** its Phase 37.1 bounded-convergence sidecar from `settle.ts`
> (~190 lines, `:353–544`) into `gates/code-review.ts` against the 39.1
> contract. **Bit-identical.** First gate to ride the `ctx.emit` port and to add
> a `VerifierPorts.codeReview` member + a convergence-sidecar port.

## Summary

The block runs the code-review verifier over the touched-file git diff, treats
"no HIGH finding" as the convergence `pass`, advances the `<draft>-CODE-REVIEW.json`
sidecar via `nextConvergence`, and branches: `bypass` (—force/—allow-code-review-failure)
proceeds + emits; `reloop` refuses with a retry message; `escalate` (no bypass)
hard-refuses + emits unconverged. It produces `codeReview` findings for SUMMARY.

Extraction introduces four collaborators on `SettleContext` (all wired in the
settle adapter; the gate imports no factory/notifier/fs directly):

1. **`verifiers.codeReview`** — `{ verify(input): Promise<CodeReviewResult> }`,
   lazily `selectCodeReviewVerifier(config)` (mirrors `verifiers.deep`).
2. **`emit.codeReviewHigh(findings, {provider, bypassed})`** and
   **`emit.codeReviewUnconverged(info)`** — wrap `emitCodeReviewHigh` /
   `emitCodeReviewUnconverged` over `selectNotifier(config)`. The
   `anomaly-notify` membership guard on `codeReviewHigh` stays **in the gate**
   (reads `ctx.gateSet`); `codeReviewUnconverged` fires unguarded, exactly as today.
3. **`diff(): string`** — memoized `collectDiffForCodeReview(cwd, touchedFiles)`
   (git diff HEAD -- files). Shared with the 39.5 security-audit gate.
4. **`codeReviewSidecar: ConvergenceSidecar`** — `read()` → `{ attemptsSoFar,
   history }` (absent/corrupt/legacy → `{0, []}`); `write(text)` →
   `atomicWriteText(path, text)`. Keeps the gate disk-free + unit-testable; the
   settle adapter owns the path (`.cadence/phases/<phase>/<draft>-CODE-REVIEW.json`)
   and the fs. 39.5 reuses the `ConvergenceSidecar` shape for its sidecar.

`SettleOpts` gains `allowCodeReviewFailure`. `SettleAccumulator.codeReview`
already exists (39.1) — the gate returns it via `summaryPatch`; settle bridges
`const codeReviewFindings = acc.codeReview` for SUMMARY assembly.

`collectHighFindings` moves into the gate (HIGH-only filter; the convergence
boolean and sidecar `findingsCount` are HIGH-only by Phase 37.1 spec).

## Decision Log

- **`ConvergenceSidecar` port, not fs-in-gate.** The sidecar is the convergence
  loop's memory; porting `read()`/`write()` keeps the gate disk-free + unit
  testable and gives 39.5 a reusable shape. The gate still owns the JSON byte
  layout; the adapter owns the path + atomic write. Rejected: gate imports
  `atomicWriteText`/`existsSync` (forces a tmp dir in every gate test).
- **`anomaly-notify` guard stays in the gate.** It is read off `ctx.gateSet`;
  the emit port is a dumb dispatcher. Preserves the asymmetry (guards
  `codeReviewHigh`, not `codeReviewUnconverged`) byte-for-byte.
- **`diff()` shared, memoized, sync.** Matches the original `execSync` shape;
  one collector serves code-review (39.4) + security-audit (39.5).
- **HIGH-only semantics preserved.** `collectHighFindings` + the HIGH-only
  `findingsCount` move verbatim — the conscious Phase 37.1 divergence from 35.1
  (which counts total findings) is retained.
