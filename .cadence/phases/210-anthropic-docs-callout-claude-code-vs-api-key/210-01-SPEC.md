# 210-01 — Docs callout: anthropic provider auth is separate from Claude Code's own login

## Objective

Add a docs callout to `docs/providers.md`'s `anthropic` section that
distinguishes "logged into Claude Code" (OAuth/subscription) from
"`ANTHROPIC_API_KEY` set" (the `anthropic` provider's actual, separately
metered requirement), modeled on the existing quota-transparency notice in
the `host-cli` section.

## Acceptance Criteria

### AC-1: Anthropic section carries an explicit auth-distinction callout
Given a reader is on `docs/providers.md`'s `## anthropic — Anthropic API`
section
When they read the setup instructions before running
`cadence config set verifier.provider anthropic`
Then a clearly marked callout tells them that being logged into Claude Code
(OAuth/subscription) does not satisfy the `anthropic` provider — it calls
the Anthropic SDK directly and requires a separately API-billed
`ANTHROPIC_API_KEY` — in tone and placement consistent with the existing
`### Quota-transparency notice` callout in the `host-cli` section.

## Constraints

- Docs-only change: `docs/providers.md`. Do not touch the runtime fallback
  warning text (`packages/core/src/verify/anthropic-verifier.ts` and its
  gate-prefixed callers) — that message already carries the same
  distinction as of phase 209 (rec-20260723-001); this phase adds the
  proactive docs callout, not a second runtime message.
- No doc-content test currently asserts on this callout's exact wording;
  none should be added purely to pin prose.
