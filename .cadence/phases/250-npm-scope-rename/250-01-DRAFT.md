# 250-01 — Rename npm scope to @thomas-powers-jr

## Objective

Rename the CADENCE monorepo's npm scope from @manehorizons to @thomas-powers-jr across all source, config, docs, and tooling so the codebase is internally consistent with the already-renamed GitHub org (see PR #360). This phase makes the change publish-ready but does NOT publish: npm publish of the 5 new @thomas-powers-jr/cadence-* packages and npm deprecate of the 5 old @manehorizons/cadence-* ones are operator-run steps after this phase's PR merges, since publishing requires the operator's authenticated npm session (account confirmed live via npm whoami -> thomas-powers-jr). New packages continue the existing 1.x version lineage rather than resetting to 1.0.0 -- this is a rename of existing software, not a new product, consistent with the standing semver policy that breaking changes ship as minor bumps until v2.0.0 (reserved for full coupling). This phase also closes a real gap found during scoping: cadence doctor --fix currently cannot detect or repair a hook entry still pointing at the old scope, because its staleness check only looks for the _managedBy: cadence marker, not command content -- so a deprecation message promising 'run doctor --fix' would otherwise be false for existing consumers.
