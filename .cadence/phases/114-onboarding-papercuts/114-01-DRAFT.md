# 114-01 — Init flip warning + handoff clock injection

## Objective

Two small papercuts: (1) warn at `cadence init` when a young repo silently gets
the `auto` gate profile that will flip `draft approve` to interactive once it
passes ~20 commits (rec-20260617-009, scoped down — the preset/profile
terminology already carries inline clarifiers, so only the flip warning
remains); and (2) kill the midnight-UTC flake in the handoff clobber test by
letting the clock be injected at the CLI boundary (rec-20260618-001).

## Acceptance Criteria

### AC-1: init warns about the future auto→interactive flip
Given `cadence init` resolves the `auto` gate profile from the git-history
suggestion (no explicit `--gate-profile`)
When the init summary is printed
Then it includes a one-line heads-up that `draft approve` becomes interactive
once the repo passes ~20 commits, and that pinning `--gate-profile auto` keeps
it hands-off — sourced from a pure, unit-tested helper that returns the notice
only in that case (not when `auto` was pinned explicitly, nor for
`standard`/`strict`).

### AC-2: handoff honors a CADENCE_NOW clock override
Given `CADENCE_NOW` is set to a valid date string in the environment
When `cadence handoff` runs
Then the SESSION doc is dated from `CADENCE_NOW` (not wall-clock), via a pure
`resolveNow(env)` helper that returns the parsed date when present+valid and
falls back to `new Date()` otherwise. (No behavior change when unset.)

### AC-3: the clobber-refusal test is deterministic
Given the `cadence handoff` "refusing to clobber exits 2" test
When it runs two handoffs in one test
Then both are pinned to the same `CADENCE_NOW` date so the collision always
fires (exit 2) regardless of wall-clock — closing the UTC-midnight flake.
