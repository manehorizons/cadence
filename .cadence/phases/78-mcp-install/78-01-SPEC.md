# 78-01 — cadence mcp install (zero-config .mcp.json)

## Objective

Add `cadence mcp install [--print] [--client <c>]` so wiring the MCP server into a host is
paste-free: it writes/merges a project `.mcp.json` (Claude Code) by default and `--print`s a
snippet for hosts whose config differs.

## Acceptance Criteria

### AC-1: Default writes/merges project .mcp.json
Given a repo with no `.mcp.json`
When the user runs `cadence mcp install`
Then a `.mcp.json` is created with `mcpServers.cadence = { command: "cadence", args: ["mcp","serve"] }`,
and the command reports the written path.

### AC-2: Merge is non-destructive and idempotent
Given a `.mcp.json` that already defines other `mcpServers`
When the user runs `cadence mcp install` (twice)
Then the existing servers are preserved, only the `cadence` key is added/updated, and a second run
produces no further change (idempotent).

### AC-3: Malformed config aborts without writing
Given a `.mcp.json` that is not valid JSON (or not a JSON object)
When the user runs `cadence mcp install`
Then the command exits non-zero with an actionable message and does NOT overwrite the file.

### AC-4: --print writes nothing
Given any repo
When the user runs `cadence mcp install --print` (or `--client claude-desktop`/`cursor`)
Then the paste-ready snippet is written to stdout, no file is created/modified, and a path hint for
the chosen client is shown.

## Constraints

- **Pure core, no MCP SDK.** The merge/snippet logic is pure and unit-testable
  (`packages/core/src/mcp/install.ts`); the file I/O is a thin service. Registering `mcp install`
  must NOT load `@modelcontextprotocol/sdk` (only `mcp serve` does) — keep the hot path clean.
- **Only Claude Code's `.mcp.json` is written.** `--client claude-desktop|cursor` is `--print`-only
  (we don't encode every host's native config path/format). Default client is `claude-code`.
- **Non-destructive merge:** preserve unknown top-level keys and existing `mcpServers`; only touch
  the `cadence` entry. Deterministic 2-space JSON + trailing newline.
- **TDD, house style:** unit tests for the pure helpers; install I/O tested against a
  `cadence-testkit` ephemeral repo. Each AC referenced by its `AC-N` token. Tests under
  `packages/core/tests/mcp/`.
