# 274-01 — Unobservable criteria: classification

## Objective

Add a settle-time classifier that recognizes when an acceptance criterion's satisfaction condition falls outside deep-verify's observable surface (`{acs, tests, diff, files}` — `deep-verify.ts:62-65`), most commonly because the AC's Then-clause makes `SUMMARY.md`/`SUMMARY.json` content itself the verification target, which is circular since that artifact does not exist until after this very settle completes. Wire the classifier into deep-verify's offender/refusal path and the force-used honesty report as a new `unobservable` verdict state (D-G, `dec-20260812-004`, superseding `dec-20260812-001` — see Evidence note below) that is reported but never rolls up as `pass` and never blocks settle on its own. Place the new state off the `AcEvidenceZ` ladder (D-H, `dec-20260812-002`). Render it distinctly in `SUMMARY.md` so an operator can tell "this wasn't checked because it structurally can't be" from "this was checked and failed." Corpus-before-code: T.2's fixture corpus is authored and proven red before T.3 exists.

**Evidence note (measured 2026-08-12, re-measured twice after the handoff's own CMD-B script proved buggy):** `.cadence/phases/**/*-DRAFT.md` corpus-wide: 1,307 total ACs. The handoff's CMD-B command (`/verbatim|pasted into the SUMMARY|paste the|stdout|command output/i` over a regex whose lookahead's bare `$` under the `m` flag truncates every AC body capture to its first line) reported 10 hits/8 phases/0.8% — that figure never actually inspected any Then-clause and silently missed phase 272's own AC-1/AC-4 (the motivating case). Re-measured with a corrected block-splitter: a broad stdout/command-output keyword sweep returns 54 hits/41 phases (4.13%), but is mostly false positives on fully-observable ACs (e.g. "Logger never writes to stdout" — observable via the diff and a linked test). Tightened to the actual circular-SUMMARY-reference signal (`pasted into the summary`, `verbatim…summary`, `this phase's own summary`), the sweep returns 5 hits across 2 phases (0.38%) — but one of those 5 is *itself* a false positive on the tightened regex: phase 29-shakedown's AC-1 ("the friction log records … the post-init summary verbatim") refers to `cadence init`'s console output logged into a friction log, not to `SUMMARY.md`/`SUMMARY.json` — a homonym on "summary," the same species of false positive as "Logger never writes to stdout." The true population found by this sweep is **4 genuine instances across 2 phases** (corrected further below by an as-built amendment): phase 272's AC-1/AC-4/AC-7 (this phase's motivating case) and phase 29-shakedown's AC-2 (a friction-log deliverable requiring "every command and its verbatim output captured" in a written SUMMARY — genuinely circular, predates deep-verify's design). Phase 29-shakedown's AC-1 is kept in T.2's fixture corpus as a real-world regression fixture proving the classifier does not fire on a keyword collision. Even a carefully tightened regex still produced one residual false positive — concrete evidence for the Boundaries section's asymmetric-safety requirement below, not a hypothetical. The corrected figure is smaller than originally claimed either way — it reinforces the staged D-G decision rather than reversing it.

**As-built amendment (2026-08-12, found by T1's independent reviewer, verified directly):** the sweep above still undercounted by one. `261-historical-ac-coverage-audit-pre-phase-239/261-01-DRAFT.md`'s AC-7 reads "...are referenced from the phase's own SUMMARY" in its Then-clause — the same `SELF_REFERENCE` circularity as phase 272's AC-7, missed by the manual grep sweep. This is genuinely 5 instances across 3 phases now (272's 3, 29-shakedown's AC-2, and 261's AC-7), not the 4/2 stated above. This does not change AC-2 or AC-3's grading — both are pinned to named, frozen fixtures rather than a live re-scan, exactly to avoid this kind of drift — but the population figure itself is corrected here rather than rewritten in place, per this repo's own inline-amendment convention for plan-time assumptions that prove false.
