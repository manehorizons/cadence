# 146-01 — cadence-recommend slash command + --top flag

## Objective

Add an optional `--top <n>` flag to `cadence recommend` and a new `/cadence-recommend` slash command (Claude Code + Codex hosts) that surfaces the top-ranked recommendations as a lightweight, non-conversational front door for picking the next milestone to scope.

## Acceptance Criteria

### AC-1: core `--top` truncation logic
Given a computed, sorted ranking of recommendations
When `synthesizeRecommendation`/`runRecommend` are called with `{ top: N }`
Then `report.ranked` is truncated to the first N entries, `report.totals.ranked` still reports the full pre-truncation count, `report.advisory` is unaffected, and omitting `top` entirely leaves output byte-identical to today.

### AC-2: renderer truncation note
Given a `RecommendationReport` where `ranked.length < totals.ranked`
When `renderRecommendMd` renders it
Then the `## Ranked` section shows a `(showing top N of M — run \`cadence recommend\` for the full list)` note; no note appears when not truncated.

### AC-3: CLI `--top <n>` flag
Given `cadence recommend --top <n>`
When `<n>` is a positive integer
Then the rendered/JSON output reflects the truncated list per AC-1; when `<n>` is `0`, negative, or non-numeric, the command refuses with exit 1 and a stderr message matching `--top must be a positive integer`.

### AC-4: Claude Code `/cadence-recommend` slash command
Given `cadence-host-claude-code install`
When it writes slash commands
Then a `cadence-recommend.md` file is written (13 total commands) whose auto-run line is `!cadence recommend --top 5` and whose trailing prose mentions `$ARGUMENTS` (for a user-requested override) and points at `cadence milestone propose`/`cadence draft new`; docs (`claude-code.md`, `quickstart.md`, `README.md`, `commands.md`) are updated to match.

### AC-5: Codex host parity
Given `cadence-host-codex install`
When it writes Codex prompts
Then a `cadence-recommend.md` prompt is written sourced from the same shared `COMMAND_GUIDANCE` entry as AC-4, keeping Claude/Codex prose parity.
