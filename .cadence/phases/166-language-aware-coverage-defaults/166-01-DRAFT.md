# 166-01 — assertion coverageMode is JS/TS-only; silently breaks by default for non-JS test suites

## Objective

Make the test-coverage gate safe and diagnosable for every project language: cadence init only defaults verification.coverageMode to 'assertion' when the detected language has real span-parsing support (js/ts today), everything else defaults to 'mention' with language-aware default test-file globs; the gate's refusal message and cadence doctor both distinguish a glob-discovery miss from an assertion-parsing miss. No new language parsing is added in this phase (that is rec-20260711-002).

## Acceptance Criteria

### AC-1: init defaults coverageMode based on detected project language
Given a fresh `cadence init` run in a project directory
When init detects the project's language from marker files (`package.json`→js/ts; `pyproject.toml`/`setup.py`/`requirements.txt`→python; `go.mod`→go; `Cargo.toml`→rust; `composer.json`→php; none found→unknown)
Then it writes `verification.coverageMode: 'assertion'` only when the detected language is js/ts; every other detected or unknown language writes `verification.coverageMode: 'mention'` and prints a stderr notice naming the detected language.

### AC-2: init writes language-aware default test-file globs
Given the same language detection as AC-1
When init writes the default test-file glob patterns for a fresh config
Then non-js/ts languages get sensible default globs for that language (python: `**/test_*.py`, `**/*_test.py`; go: `**/*_test.go`; rust: `tests/**/*.rs`, `**/*_test.rs`; php: `**/*Test.php`, `tests/**/*.php`) instead of today's TS-only defaults.

### AC-3: test-coverage gate error distinguishes glob-miss from span-miss
Given the `test-coverage` gate fails to find assertion-mode evidence for an AC
When it renders its refusal message
Then it names which of two distinct causes applies — "no test files matched configured globs" vs. "test files matched but no assertion-shaped span found for AC-N" — each with its own suggested fix.

### AC-4: doctor flags assertion mode paired with an unsupported language
Given `cadence doctor` runs against a project with `verification.coverageMode: 'assertion'`
When the detected project language (per AC-1's detection) is not js/ts
Then doctor reports a check naming the mismatch and suggesting `cadence config edit coverageMode`.
