# 163-01 — Handoff/Resume Hardening — Freshness & Completion Gates

## Objective

Make cadence resume/handoff detect staleness themselves — fetch-backed git facts, an origin-ahead banner, an unfilled-narrative gate, and a capped files-in-play block — so the CLI enforces handoff completeness and freshness instead of relying on skill-level discipline.

## Acceptance Criteria

### AC-1: fetch-backed git facts
Given a handoff is being written and opts.noFetch is not set
When readGitFacts runs
Then it best-effort git-fetches first and reports fetched:true, or fetched:false on any fetch failure (offline/no remote), never throwing

### AC-2: origin-freshness probe
Given a git repo with an upstream configured
When checkRemoteFreshness runs
Then it fetches origin and reports checked:true with ahead/behind counts, or a soft checked:false with a reason (not-a-repo/detached/fetch-failed/no-upstream) on any failure — the fetch touches remote-tracking refs only

### AC-3: resume surfaces the origin-ahead banner
Given cadence resume finds a handoff and remoteCheck is enabled
When the probe reports behind > 0
Then resume prints a stale-handoff warning naming the commit count and inspect command, attaches remote to the JSON result, and --offline or config.resume.remoteCheck=false skips the probe entirely

### AC-4: unfilled FILL-IN sections are flagged
Given a replayed SESSION doc still has one or more <!-- FILL IN --> markers
When cadence resume replays it
Then findUnfilledSections names each such section once and resume prints a warning telling the reader to treat them as absent

### AC-5: handoff --check completion gate
Given the freshest SESSION doc either has or lacks unfilled sections
When cadence handoff --check runs
Then it exits 0 and prints complete when clean, exits 3 and lists the unfilled sections otherwise, and exits 1 when no doc exists

### AC-6: handoff files-in-play capped
Given the handoff-scope context packet is built
When runContext selects files for the doc
Then files come from the same selected/top-N recommendations as every other scope, not every scored recommendation, shrinking the files-in-play block

### AC-7: wrapper guidance teaches the new gates
Given the cadence-handoff and cadence-resume slash-command wrappers are installed
When an agent reads their trailing guidance text
Then cadence-handoff's text instructs running --check before finishing, and cadence-resume's text instructs honoring the origin-ahead banner and unfilled-section warning
