# 124-01 - Lead onboarding with a 60-second no-risk tutorial

## Objective

Make the throwaway tutorial and `init --demo` the first visible onboarding path so new users can see CADENCE work before hand-editing a DRAFT.

## Acceptance Criteria

### AC-1: README leads with no-risk tutorial
Given a new user reads the README quickstart
When they reach the first runnable command after install
Then they see a throwaway tutorial command before the real-repo `init --demo` flow.

### AC-2: Quickstart introduces the demo path before manual editing
Given a new user follows `docs/quickstart.md`
When they complete prerequisites
Then the guide points them to `cadence tutorial` and `cadence init --demo` before the manual phase-editing walkthrough.

### AC-3: Website landing page mirrors tutorial-first positioning
Given a visitor opens the documentation website landing page
When they scan the first-page cards
Then the start path emphasizes Install, Quickstart, and a no-risk tutorial/demo route.

### AC-4: Existing manual workflow remains documented
Given an experienced user wants to drive a real phase manually
When they continue past the tutorial/demo fast path
Then the manual DRAFT workflow remains available and accurate.
