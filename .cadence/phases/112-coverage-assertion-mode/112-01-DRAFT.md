# 112-01 — Deepen the coverage gate beyond AC-token string-matching (assertion mode)

## Objective

Add an opt-in `verification.coverageMode: 'assertion'` so the test-coverage gate
counts an `AC-N` token only when it sits inside an asserting `it()`/`test()`
block, closing the "mentioned-not-tested" false positive while keeping today's
lenient `mention` behavior as the default.

## Acceptance Criteria

### AC-1: coverageMode config field
Given a config with no `verification.coverageMode`
When the config is parsed
Then it defaults to `'mention'`, accepts `'assertion'`, and rejects any other value.

### AC-2: assertion-aware span detection
Given a test file's source text
When `findTestSpans` scans it (string/comment-aware, no AST)
Then an `AC-N` inside an `it()`/`test()` block that asserts is reported as a
qualifying span, while a bare comment, a `describe()` label, or an
assertion-less block is not — and parens inside a title string do not break it.

### AC-3: mode-aware coverage scan + classification
Given a repo scanned with `mode: 'assertion'`
When an AC is inside an asserting block / only in a comment / nowhere
Then it is respectively covered / weakly-linked (`weaklyLinkedAcs`) / uncovered.

### AC-4: mention mode unchanged (regression)
Given a comment-only `AC-N` reference
When the repo is scanned in `mention` mode (or default)
Then the AC is counted as covered exactly as before this phase.

### AC-5: assertion-mode gate refusal message
Given the settle coverage gate runs in `assertion` mode
When an AC is mentioned-but-not-asserted vs entirely absent
Then the refusal names the mode and emits a distinct "not inside an asserting
it()/test() block" hint for the weak link and the plain "has no linked test"
message for the absent one.

## Boundaries

- DO NOT change `mention`-mode behavior — it must stay byte-for-byte identical (default).
- DO NOT flip CADENCE's own `verification.coverageMode` to `assertion` this phase.
- DO NOT add an AST/TypeScript parser, a new dependency, or any network call — deterministic + offline only.
- DO NOT make the assertion-token set configurable this phase (YAGNI).
