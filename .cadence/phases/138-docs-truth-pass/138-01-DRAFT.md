# 138-01 — Docs truth pass: slash-command counts + start menu completeness

## Objective

rec-20260701-011's audit evidence (R-11/F9-F10) named two things. Investigation
found one claim doesn't reproduce: the README flagship walkthrough was
live-tested and genuinely refuses on the coverage gate exactly as documented
— no fix needed there. The other claim is real: the slash-command count is
published inconsistently (README "eleven", quickstart "nine", claude-code.md's
own TOC "9" vs its section header "12" — a broken anchor), while code truth
