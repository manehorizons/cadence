# 103-01 — Release v1.24.0 — recommendation retention

## Objective

Ship the v1.24 recommendation-retention milestone: document the manual + automatic
soft-archival surface (commands + config) and stage the changeset that bumps all four
published packages `1.23.0 → 1.24.0`.

## Acceptance Criteria

### AC-1: commands.md documents the archive surface
Given `docs/reference/commands.md`
When a reader looks up the `recommendation` command
Then `archive` / `unarchive` subcommands and `list --archived` are documented, and the
`promote` behavior note records that `shipped`/`rejected` auto-archive.

### AC-2: config.md documents `recommendations.autoArchive`
Given `docs/reference/config.md`
When a reader looks up retention config
Then a `recommendations` section documents `autoArchive` (type, default `true`,
recoverable, the three triggers) and it is linked from the table of contents.

### AC-3: a changeset stages the lockstep minor bump
Given `.changeset/`
When the release is cut
Then a changeset declares a `minor` bump for all four published packages
(`core`, `types`, `host-claude-code`, `host-codex`) describing v1.24.

## Tasks

### T1: Document the archive command surface
- files: `docs/reference/commands.md`
- action: add `#### recommendation archive` + `#### recommendation unarchive` sections
  (after `promote`); add `--archived` to the `recommendation list` options; note the
  auto-archive behavior in `promote` (shipped/rejected) and that `show` is
  archive-aware. Update the `recommendation` sub-TOC.
- verify: `grep -n "recommendation archive" docs/reference/commands.md` resolves.
- done: AC-1

### T2: Document the config field
- files: `docs/reference/config.md`
- action: add a `## recommendations` section (mirror the `## handoff` shape) covering
  `recommendations.autoArchive` (boolean, default `true`, recoverable; triggers:
  shipped/rejected on promote, converted on settle); add it to the table of contents.
- verify: `grep -n "recommendations.autoArchive" docs/reference/config.md` resolves.
- done: AC-2

### T3: Stage the release changeset
- files: `.changeset/rec-retention.md`
- action: write a changeset with `minor` for all four published packages summarizing
  v1.24 (manual + auto soft-archival; `recommendation archive/unarchive`,
  `list --archived`, `recommendations.autoArchive` default-on).
- verify: `cat .changeset/rec-retention.md` lists the four packages as `minor`.
- done: AC-3

## Boundaries

- DO NOT run `pnpm changeset version` or bump `package.json`/`CLAUDE.md` inside the
  settled phase commit — that is the post-settle release-cut step (same flow as
  v1.23.0), done on this branch after settle so the doc-sync gate sees 1.24.0.
- DO NOT change engine behavior — this is a docs + changeset release phase only.
- DO NOT touch `docs/concepts.md` gate matrix (unrelated).
