# 130-01 — First real phase agent prompt

## Objective

Add `cadence agent-prompt` and an `init` output block that hand the user a copy-paste prompt telling their AI agent to scaffold a real first CADENCE phase (DRAFT with testable ACs, stop at approval), with one pure renderer shared by both surfaces so they cannot drift.

## Acceptance Criteria

### AC-1: pure renderer substitutes the goal or a placeholder
Given the pure `renderAgentPrompt(goal?)` renderer
When it is called with a goal, with no goal, and with a blank/whitespace goal
Then a supplied goal is substituted into both the goal line and the `cadence draft new --title` value; an absent or blank goal yields the literal `<your goal>` placeholder; and the output always contains the load-bearing tokens `cadence draft new`, `--template`, `AC-1`, `Do not approve`, and `cadence settle`.

### AC-2: `cadence agent-prompt` prints the prompt with flags
Given the registered `cadence agent-prompt` command
When it is run bare, with `--goal "<text>"`, and with `--json`
Then bare output equals the renderer's placeholder output and exits 0; `--goal` bakes the goal into the prompt; and `--json` emits `{ goal, prompt }` with `goal` null when omitted and the matching rendered `prompt`.

### AC-3: `init` prints the agent-prompt block
Given a fresh `cadence init` run in a non-interactive shell
When init prints its next-steps output
Then the output includes a "Hand it to your AI agent" block containing the renderer's placeholder output verbatim plus a `cadence agent-prompt --goal` reprint pointer, and init still prompts for nothing (exits 0 non-interactively).

### AC-4: the prompt teaches the CLI agent workflow
Given the rendered prompt text
When it is inspected
Then it instructs the agent to run `cadence draft new --template <bugfix|feature|refactor>`, to tag acceptance criteria `AC-1, AC-2, …`, and to stop at approval — it never tells the agent to run `cadence draft approve` itself.

### AC-5: the command is discoverable
Given the onboarding command map produced by `buildQuickstart`
When the map is inspected
Then it lists an `agent-prompt` entry, and the reference docs (`commands.md`, `cli.md`, `quickstart.md`, `claude-code.md`) document the command.

- DO NOT move the prompt text into `cadence-types` — keep it in `render.ts` (no second consumer yet).

- DO NOT touch the gate engine, verifier providers, or any state-machine code.
- DO NOT write the prompt to a file; stdout only.
