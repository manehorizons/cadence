# 249-01 — Post-gate refusal SUMMARYs + finding-durability ledger closeout

## Objective

Extend phase 247's refused-SUMMARY writer (`writeRefusedSettleSummary`) to
the three post-gate `settle.ts` refusal families that still exit 1 with no
SUMMARY at all — AC derivation, anomaly/skill-audit, and evidence-floor —
so every refusal with a resolved draft/gate context leaves a record
identical in shape to the gate-loop refusal family phase 247 already
hardened, while durably closing out the finding-durability ledger
bookkeeping (`rec-20260731-010`, `rec-20260712-006`) that motivated this
arc.

## Acceptance Criteria

`rec-20260712-006`) have run inside this worktree

`cadence decision list --filter-rec rec-20260731-010` (exactly one active

Then every listed assertion holds, with command output captured as the

AC cannot depend on evidence that only exists after the AC is evaluated.)

### AC-2: Every in-scope post-gate refusal writes a refused SUMMARY
Given a refusal in the AC-derivation, anomaly/skill-audit, or
evidence-floor family (verified against current source before
implementation — re-derive the exact call sites, don't trust the line
numbers above blindly)
When settle exits 1
Then a refused SUMMARY is written via the unchanged, phase-247

inheriting conditional `contentHash` and snapshot-sibling behavior
identically to the gate-loop refusal family — a findings-bearing
evidence-floor (or AC-derivation, or skill-audit) refusal preserves its
findings exactly as a gate-loop refusal does.

(nothing synthesized) — an invariant `writeRefusedSettleSummary` has held
since it was first introduced (phase 170), and phase 247 already depends on
holding it unmodified while reusing the same writer.
