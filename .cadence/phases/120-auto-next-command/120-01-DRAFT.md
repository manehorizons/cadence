# 120-01 - Auto-derive phase id and simplify settle syntax

## Objective

Reduce first-loop command friction by letting `draft new` infer phase/id defaults and giving `settle run` readable pass shorthands.

## Acceptance Criteria

### AC-1: draft new can infer phase and task number
Given Cadence is IDLE and the user supplies only `--title`
When they run `cadence draft new --title "My Feature"`
Then Cadence creates the next-free phase with a title-derived slug and task `01`.

### AC-2: explicit draft new positionals still work
Given existing scripts use `cadence draft new <phase> <num>`
When they run the old positional form
Then behavior remains compatible.

### AC-3: settle supports pass-all shorthand
Given all build tasks are done
When the user runs `cadence settle run --pass-all`
Then Cadence records every draft AC as passing without requiring repeated `--ac AC-n=pass` pairs.

### AC-4: settle supports per-AC pass shorthand
Given a draft has multiple ACs
When the user runs `cadence settle run --ac-pass AC-1 AC-2`
Then Cadence records those ACs as passing while preserving existing `--ac` fail/note syntax.

### AC-5: progress suggests a copy-pasteable draft command
Given Cadence is IDLE
When the user runs `cadence progress`
Then the suggested command is runnable without replacing positional placeholders.
