# 106-01 — cadence start: interactive shell + wiring

## Objective

Build the `cadence start` CLI shell over the phase-105 core: TTY-aware
pick/confirm loop, uniform subprocess-spawn dispatch, `--pick`/`--yes`/`--json`,
register the command, and cross-reference it from `init` and `quickstart`.

## Acceptance Criteria

### AC-5: `--json` emits the menu and never spawns
Given `runStart` with `{ json: true }`
When invoked
Then it writes the structured menu JSON and exits 0 without spawning.

### AC-6: A non-interactive shell prints the menu and exits 0
Given `runStart` with `isTty: false` and no `--pick`
When invoked
Then it prints the menu, exits 0, and never spawns (CI/pipe-safe).

### AC-7: `--pick <n> --yes` dispatches the right runner + args; command is registered
Given `runStart` with `{ pick, yes: true }`
When a core option is picked
Then it spawns runner `cadence` with that option's args; when a host option is
picked it spawns runner `npx` with the install args. The `start` command is
registered on the CLI program.

### AC-8: An invalid `--pick` exits non-zero and never spawns
Given `runStart` with an out-of-range `pick`
When invoked
Then it writes an error, exits non-zero, and never spawns.

### AC-9: Confirm gates the run
Given an interactive run without `--yes`
When the confirm resolves false
Then the command is printed and nothing spawns; when it resolves true the option
is spawned.

### AC-10: Interactive prompt drives selection
Given an interactive run with no `--pick`
When the prompt returns null
Then it quits with exit 0 and no spawn; when the prompt returns an option, that
option is dispatched.

### AC-11: A non-zero spawn exit code is propagated with a fallback
Given a dispatched option whose spawn exits non-zero
When `runStart` returns
Then the exit code is propagated and a "run it yourself" fallback line is shown.

### AC-12: The init option is annotated when the repo is initialized
Given `runStart` where the state probe reports initialized
When the menu prints
Then the init option carries the "already set up" annotation.

### AC-13: `cadence start` is discoverable from the other front doors
Given the onboarding surfaces
When inspected
Then the `quickstart` command map lists a `start` entry and the `init`
next-steps output references `cadence start`.
