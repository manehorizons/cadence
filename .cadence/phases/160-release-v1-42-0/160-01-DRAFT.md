# 160-01 — Release v1.42.0

## Objective

Bundle five independently-merged, unreleased phases (155, 156, 157, 158, 159) into a single lockstep version bump across all four published packages, with changesets, updated changelogs, and an updated CLAUDE.md release narrative.

## Acceptance Criteria

### AC-1: Changesets added for all five bundled phases
Given phases 155-159 merged to main without changesets
When five changeset files are added under `.changeset/`
Then each names all four published packages with the correct bump type (minor for feature phases 155/156/158/159, patch for the pure bugfix phase 157)

### AC-2: Version bump applied in lockstep
Given the changesets are in place
When `pnpm changeset:version` runs
Then all four published packages (`cadence-core`, `cadence-types`, `cadence-host-claude-code`, `cadence-host-codex`) show version `1.42.0` and each package's `CHANGELOG.md` gains a `1.42.0` entry

### AC-3: CLAUDE.md release narrative updated
Given the doc-sync gate requires CLAUDE.md to mention any new canonical version
Then CLAUDE.md's release narrative names `1.42.0`, summarizes all five bundled phases, and the doc-sync checker (`.githooks/check-doc-sync.sh 1.42.0`) passes against it

### AC-4: Full monorepo verification green
Given the version bump and doc changes are complete
Then `pnpm build && pnpm typecheck && pnpm lint && pnpm test` all pass with no regressions
