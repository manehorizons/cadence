# 123-01 - Sourced competitive positioning

## Objective

Create a local-only, source-backed competitive positioning brief for CADENCE's in-loop enforcement wedge.

## Acceptance Criteria

### AC-1: Source-backed local artifact
Given the launch-prep artifacts are intentionally local-only
When `launch/COMPETITIVE.md` is written
Then it is date-stamped with the retrieval date, cites primary/public sources for each competitor claim, and remains under an ignored path.

### AC-2: Narrow defensible wedge
Given the market includes spec scaffolders, IDE workflows, and PR review bots
When the positioning statement describes CADENCE
Then it uses the defensible claim "npm-distributed, host-agnostic agent workflow harness that can refuse phase completion on acceptance-criteria-linked evidence inside the loop" and avoids broad "only tool that gates AI code" wording.

### AC-3: Competitor taxonomy
Given Spec Kit, OpenSpec, BMAD, Kiro, CodeRabbit, Greptile, and Qodo are named alternatives
When the competitive brief compares them
Then it separates spec/workflow scaffolders from PR-review quality gates and states where CADENCE differs without implying those tools are weak or absent from their own categories.

### AC-4: Objection handling
Given launch conversations will challenge the claim
When the brief is read
Then it includes an objection FAQ plus an overclaim bank of phrases to avoid.

### AC-5: No public-doc drift
Given this is launch prep, not public positioning
When the phase settles
Then no README, package docs, public marketing page, or tracked docs copy is changed by this phase.

- files: `launch/COMPETITIVE.md`

- action: Separate spec/workflow tools from PR-review bots, then add objection answers and an overclaim bank.

- done: AC-5
