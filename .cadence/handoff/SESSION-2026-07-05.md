## Carry-forward gotchas

- **The regex fix pattern for wrapped Given/When/Then clauses**: both
  `spec-parser.ts` and `draft-parser.ts` now use
  `/Given\s+([\s\S]+?)(?=\nWhen\s|\nThen\s|$)/`-shaped regexes (non-greedy
  `[\s\S]+?` with a next-label-or-end-of-block lookahead) instead of
  `/Given\s+(.+)/`. If you touch AC-clause parsing again, keep the two files'
  logic in lockstep by hand — there is still no shared module between them
  (deliberate; see spec-parser.ts's own header comment), so a future fix to
  one and not the other silently reintroduces this exact bug class.
- **Objective extraction is now the full section text, not the first line**
  in both parsers (`extractSection(body, 'Objective')` used directly, no
  `.split('\n')[0]`). `extractSection` already isolates content up to the
  next `## ` heading, so this was a pure truncation removal, not a rewrite.
- **`gh pr merge --squash --delete-branch` leaves a stale
  `remotes/origin/<branch>` ref locally** even after deleting local+remote —
  cosmetic only (a `git fetch --prune` clears it), not a sign the delete
  failed.
