## Conventions established (carry forward)

- **Tag every milestone close.** Annotated tag, message `vX.Y.Z — <theme> (Phases …)`, on the last phase's settle commit (or the consolidating docs commit when one exists). Standing user instruction.
- **Two-commit-per-phase**: `feat/ci/release(...): … (Phase N)` then `chore: settle Phase N — …`. `.cadence/` artifacts go only in the settle commit.
- **Dogfood loop runs auto×standard** (config has no `profile` → `auto`; DRAFTs use `tier: standard`) so the very gates being built don't self-trigger. Phases that built strict×complex gates (25.1/25.2) were exercised via tests, not the dogfood loop.
