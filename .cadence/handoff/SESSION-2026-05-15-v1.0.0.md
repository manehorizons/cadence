### Post-1.0 hardening (not roadmap phases — direct fixes)

- **`896a140` fix(core): atomic-write rename retry.** Root cause of the long-standing flaky `dispatcher.test.ts > "skill-invoke caps at 100 entries with FIFO drop"`: `state/atomic-write.ts` did a bare `rename(tmp,path)`; Windows transiently fails it (EPERM/EACCES/EBUSY) under parallel load → dropped state write → FIFO test < 100. Fixed: `renameWithRetry` (10 attempts, linear backoff, only on those codes) + unique per-write temp name `<path>.<pid>.<rand>.tmp`. Verified `turbo run test` ×3 parallel all green. **Flake is resolved.**
- **`39b9158` / `8cc78a2` CI gate.** GitHub Free + private repo cannot use branch protection OR rulesets (both 403 — need Pro or public; confirmed via `gh api`). Decision (user): stay private, enforce client-side. Added `ci-success` aggregator job to `ci.yml` (one stable status context vs six brittle matrix-cell names, ready for a future server-side rule), and a tracked `.githooks/pre-push` that runs `pnpm turbo run lint typecheck test build` before any push updating `refs/heads/main` and aborts on failure. Wired locally via `git config core.hooksPath .githooks`. Bypass: `git push --no-verify`.
