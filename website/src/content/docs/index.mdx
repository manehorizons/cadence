CADENCE scaffolds and runs the **DRAFT → BUILD → SETTLE** loop on your project —
and uses that same loop on itself. Quality gates are configurable per profile and
tier, and the always-fire build/test gate will refuse to close a phase whose tests
do not pass, even when the AI marked the task done.

> **"Your CI is green. Cadence still said no."** An agent hits a failing test, guts
> the assertion, and leaves a plausible excuse. The suite goes green, tasks get
> marked DONE. Then `cadence settle run --auto` refuses anyway — naming the specific
> AC and the specific dodge. Real output, offline, mock verifier, zero npm deps:
> [full 4-beat narrative](https://github.com/manehorizons/cadence/blob/main/docs/DEMO.md).
>
> Also see: [the $100/3 demo](https://github.com/manehorizons/cadence-demo-billsplit)
> (arithmetic bugs, not agent cheating) — a lost-penny bill-split bug the
> `build-test-must-pass` gate blocks even though the AI marked the task DONE.
